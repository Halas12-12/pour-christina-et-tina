# Pour Christina et Tina ❤️

Site souvenir avec 9 photos et une vidéo de fond.

## Publication GitHub Pages

1. Créer un dépôt GitHub.
2. Importer le contenu de ce dossier à la racine du dépôt.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.

Attention : un dépôt public rend les photos et la vidéo accessibles au public.
